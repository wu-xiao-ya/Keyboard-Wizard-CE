# Changelog

## Fabric 26.3 stable - 2026-09-27

- Retargeted `ce/fabric-26.3` from the 26.3 snapshot test line to stable Minecraft 26.3 + Fabric.
- Dropped snapshot, pre-release, and release-candidate dependency ranges.
- Uses Fabric Loader 0.19.5 and Fabric API 0.161.0+26.3.

## Fabric 26.3 snapshot port - 2026-07-06

- Added `ce/fabric-26.3` for the Minecraft 26.3 snapshot test line on Fabric.
- Uses Fabric Loom with official Mojang mappings.
- Carries the modern CE feature set: F7 entry, Controls screen icon entry, layout switching, search, key-based filtering, help tooltip, CE background, and bundled CE icon assets.
