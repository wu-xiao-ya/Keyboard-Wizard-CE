# Keyboard Wizard CE Forge 1.12.2

Community Edition / unofficial port of Keyboard Wizard for Minecraft 1.12.2 on Forge/Cleanroom.

- Branch: `ce/forge-1.12.2`
- Mod id: `keyboard_wizard_ce`
- CE version: `1.0.2beta`
- Target: Minecraft `1.12.2` + Forge `14.23.5.2847`
- Current author: WuXiaoYa
- Original authors: MrNerdy42, Tapio
- Art assets: WI_8614_ice

## Current Branch Features

- Optional Hide Key Binding compatibility: hidden key bindings are not shown or modified by Keyboard Wizard CE.
- Main keyboard, numpad, and auxiliary key layouts are available from the CE screen.
- The left-side list and categories respect visible key bindings only.
