# 按键精灵社区版（Keyboard Wizard CE）

Minecraft 1.21.4 + NeoForge target for Keyboard Wizard CE, the Community Edition port of Modern KeyWizard.

- Minecraft 1.21.4
- NeoForge 21.4.161 or later on Minecraft 1.21.4
- Java 21
- Mod ID `keyboard_wizard_community_edition`
- CE version `1.1.0`
- Community Edition maintainer WuXiaoYa
- Original authors MrNerdy42 and Tapio
- Art assets by WI_8614_ice
- Port date 2026-11-17

Press F7 or select the keyboard icon in the vanilla Controls screen to open Keyboard Wizard CE. The screen includes keyboard, numpad and auxiliary layouts. Middle-click a key to filter its bindings, or right-click a key to clear the selected binding assigned to it.
